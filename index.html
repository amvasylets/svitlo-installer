📋 Як встановити

  1. Підключіть плату до комп'ютера USB-кабелем. Кабель має передавати дані — не лише заряджати.
  2. Натисніть ⚡ Встановити прошивку. У списку пристроїв оберіть USB JTAG/serial debug unit і натисніть Підключитися (Connect).
  3. У вікні, що відкриється, натисніть Install Svitlo.
  4. Вікно Erase device («стерти плату?»), галочка Erase device:
    • нова плата — поставте галочку;
    • оновлення вже налаштованої плати — не ставте, тоді Wi-Fi, черга й інші налаштування збережуться.
  5. Натисніть Next, потім у вікні Confirm Installation — Install. Зачекайте 1–2 хвилини, доки запис дійде до 100%. Кабель не від'єднуйте.
  6. З'явиться Installation complete! — плата перезапуститься сама. Якщо світлодіод не блимає — від'єднайте й знову під'єднайте кабель.
  7. Нова плата роздасть Wi-Fi svitlo-setup: підключіться до неї телефоном — сторінка налаштування відкриється сама. Оберіть домашній Wi-Fi, введіть пароль, номер черги та номер плати: esp1…esp6 (на одній черзі може бути до 6 плат чи телефонів — у кожної свій номер).

🔌 Якщо плата не підключається

  1. Закрийте Arduino IDE та інші програми, що можуть тримати порт (монітор порту).
  2. Спробуйте інший кабель або інший USB-роз'єм комп'ютера.
  3. Режим прошивки вручну: затисніть кнопку BOOT на платі, під'єднайте кабель (або коротко натисніть RESET), відпустіть BOOT і натисніть «Встановити» ще раз. Після встановлення від'єднайте й знову під'єднайте кабель.
  4. Windows не бачить плату — оновіть Chrome/Edge; для ESP32-C3 SuperMini окремі драйвери зазвичай не потрібні.
